# 媒体信息与情绪操控识别 SOP

## 1. 目的

本流程用于审视新闻、社交媒体内容、广告、评论和转发信息中，是否存在选择性呈现事实、隐去关键信息或利用情绪影响判断的情况。目标是提高核查质量，不是预设媒体或作者有恶意。

“媒体 PUA”是这张图使用的比喻性标签，不是经核查即可自动成立的结论。分析时优先描述可观察到的做法及其证据，例如“未交代利益关系”或“标题把相关性表述成因果”，避免仅凭强烈感受给内容定性。

## 2. 适用范围

- 重大新闻、公共议题和争议性事件的内容核查。
- 可能影响健康、财务、安全、声誉或重要决策的信息。
- 需要判断内容是否充分、平衡，以及情绪表达是否妨碍独立判断的场景。

本流程不替代专业事实核查、法律意见或紧急情况下的官方指引。

## 3. 操作原则

1. **先分开事实、推断与意见**：记录哪些是可验证陈述，哪些是解释、预测或价值判断。
2. **核查原始材料**：优先找原始文件、完整讲话、数据集、研究论文、当事方声明和现场材料，不只依赖二手转述。
3. **保留上下文**：检查时间、地点、对象、统计口径、样本范围、剪辑前后内容及事件背景。
4. **寻找替代解释**：主动查找与当前叙事不同的可信材料；不同观点不等于证据质量相同。
5. **按证据强度下结论**：区分“已证实”“有争议”“证据不足”和“无法核实”。
6. **审视手法，不猜动机**：除非有直接证据，不推断作者或机构故意操纵。

## 4. 标准流程

### 步骤一：保存并界定内容

- 保存原文、链接或截图，并记录发布者、发布时间、平台和获取时间。
- 明确要核查的具体主张；把一段复杂内容拆成可验证的小问题。
- 区分原始发布内容与转发者添加的标题、配文或剪辑。

### 步骤二：检查“内容加工层”

逐项检查以下四类现象。勾选只代表需要进一步核查，不等于已经证明操控。

| 检查点 | 核查问题 |
|---|---|
| 抹除（Erase） | 是否删去关键背景、历史记录、反例或相关成就？删去部分会不会改变理解？ |
| 隐藏（Hide） | 是否未说明资金、利益关系、数据来源、统计口径、关键限制或不利事实？ |
| 夸大（Magnify） | 是否把个案说成普遍现象，把相关性说成因果，或夸大牺牲、善意与效果？ |
| 神化（Sanctify） | 是否把个人或机构塑造成不可质疑的英雄、权威或救世者，并弱化其责任与利益？ |

### 步骤三：检查“心理影响层”

| 检查点 | 核查问题 |
|---|---|
| 贬低（Devalue） | 是否反复强调受众无知、无能或低人一等，使人放弃判断？ |
| 抬高（Elevate） | 是否把某一方描述成永远正确、专业或道德高尚，却不提供可检验依据？ |
| 绑定（Bind） | 是否利用儿童、疾病、弱势群体、灾难或生死议题制造愧疚、恐惧或服从压力？ |
| 压制（Silence） | 是否把提问、质疑或要求证据直接说成冷漠、不忠或不道德？ |
| 植入（Implant） | 是否重复灌输单一结论或口号，让结论取代证据和推理？ |

### 步骤四：交叉核验

- 对关键主张寻找至少一个独立、可信的来源；高影响事项尽量找到原始来源。
- 比对不同来源对同一事实的描述，注意来源是否相互引用同一未经证实的材料。
- 核对数字的分母、时间范围、样本和定义；核对图片或视频的出处、日期及是否经过剪辑。
- 搜索可能推翻当前判断的证据，而不只是寻找支持自己立场的材料。
- 对无法访问的材料或尚未确认的说法，明确标注“待核实”。

### 步骤五：评估证据并形成结论

给每项重要主张记录：主张原文、支持证据、反向证据、来源质量、上下文和不确定性。可使用以下状态：

- **已证实**：有可靠证据直接支持，关键上下文一致。
- **部分属实**：核心事实有依据，但遗漏背景或表达夸大。
- **有争议**：可靠来源存在分歧，现有材料不足以定论。
- **证据不足**：目前找不到足以支持该说法的材料。
- **不实**：可靠证据与该说法直接矛盾。
- **无法核实**：来源或材料不可得，暂时无法判断。

如果发现多项加工或情绪施压信号，可描述其组合和影响；不要把信号数量机械地当成“操控成立”的证明。

## 5. 风险信号速查

出现以下现象时，暂停转发或据此作重大决定，先核查：

1. 只呈现部分事实，且省略部分会改变结论。
2. 不给出数据、原始材料或可检验的推理过程。
3. 反复煽动恐惧、愤怒、羞耻或紧迫感，催促立即站队或行动。
4. 把某一方描述成绝对完美，把另一方一概污名化。
5. 将提问者描述为冷漠、愚蠢或不道德，以阻止核查。
6. 结论被反复重复，却始终没有新增证据。

单个信号可能也有合理解释（例如突发事件中信息尚不完整）。结合上下文、证据和更正记录判断。

## 6. 快速处置

- **高影响、低证据**：不转发，不作不可逆决定；寻找原始资料和专业意见。
- **强烈情绪、时间压力**：先暂停，记录内容实际证明了什么、没有证明什么。
- **来源不明或剪辑片段**：追溯完整版本、原始发布者和发布时间。
- **核查后发现错误**：更正自己的转发或判断，并保留更正说明。

## 7. 核查记录模板

```text
内容标题/主张：
原始来源与链接：
发布者 / 发布时间 / 核查日期：
内容类型：事实陈述 / 推断 / 意见 / 号召

需要核查的具体问题：
支持证据（来源与上下文）：
反向证据或替代解释：
数据、图片、视频核验：
发现的内容加工信号：
发现的情绪施压信号：
来源独立性与可信度：
结论状态：已证实 / 部分属实 / 有争议 / 证据不足 / 不实 / 无法核实
不确定性与后续核查：
```

## 8. 完成标准

一份合格的核查记录应当：

- 明确要核查的具体主张，而不是只给内容贴标签。
- 引用可追溯的证据并保留必要上下文。
- 说明相反证据、局限和不确定性。
- 将内容表现与发布者动机分开。
- 给出与证据强度相称的结论，并在新证据出现时更新。

# 记忆层

记忆层保存原始但有价值的经验信息，强调上下文、来源、生命周期和后续整理路径。

## 记忆类型

推荐使用以下 `memory_type`：

- `preference`：用户或团队偏好
- `decision`：决策及决策原因
- `constraint`：长期约束或禁止项
- `experience`：实践经验
- `incident`：故障、缺陷或失败记录
- `feedback`：执行反馈
- `context`：项目背景
- `observation`：待验证观察

## 生命周期

- `short`：短期记忆，仅服务当前任务或近期事项
- `medium`：中期记忆，预计会在一段时期内复用
- `long`：长期记忆，跨多个任务有效
- `permanent`：稳定规则、核心决策或长期事实

生命周期不是永久承诺。每条记忆都可以被复核、降级、合并或归档。

## 创建要求

每条记忆必须包含：来源、摘要、上下文、置信度、生命周期、适用范围和后续动作。

使用 `_template.md` 创建新记忆，并更新 `../indexes/memory-index.md`。

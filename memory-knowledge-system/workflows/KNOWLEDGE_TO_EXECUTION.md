# 知识到执行工作流

## 触发条件

开始新任务、设计方案、处理故障或执行既有 SOP 时启动此流程。

## 步骤

1. 从任务目标提取检索词、技术范围、项目范围和约束。
2. 检索 `knowledge/`，优先选择 `active` 或 `reviewed` 内容。
3. 检查版本、更新时间、来源、限制和适用条件。
4. 将适用知识引用到当前任务的 D 阶段。
5. 在 P 阶段检查知识之间是否冲突，以及是否需要更新。
6. 按 DPIRA 执行：`(D → P → I ⇄ R) × N → A`。
7. 在 R 和 A 阶段验证实际结果是否符合被引用知识。
8. 将执行过程中的新事实、偏差、失败和改进写入记忆层。
9. 对需要长期保留的反馈启动记忆转知识流程。

## 引用格式

```markdown
依据：[KB-YYYYMMDD-XXXX](../knowledge/KB-YYYYMMDD-XXXX.md)
适用范围：
本任务采用的结论：
已知限制：
```

## 知识不适用时

如果知识过时、范围不匹配、来源不明或与当前代码库冲突：

1. 不静默使用。
2. 在记忆层记录冲突或反馈。
3. 必要时将知识标记为 `deprecated` 或 `draft`。
4. 重新完成 D/P 后再实施。

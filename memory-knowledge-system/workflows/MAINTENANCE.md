# 维护与清理工作流

## 日常维护

- 新增记忆后补充来源、生命周期和关联知识。
- 新增知识后补充来源记忆、验证依据和索引。
- 任务完成后记录实际使用结果和反馈。

## 定期复核

按项目节奏检查：

1. 是否存在过期的 `active` 知识。
2. 是否存在没有来源的知识。
3. 是否存在没有被使用或长期未验证的记忆。
4. 是否存在重复、冲突或可以合并的内容。
5. 是否有链接失效、版本缺失或状态不一致。

## 状态变更

```text
draft → reviewed → active → deprecated → archived
```

如果新证据推翻旧结论，应保留旧文件，建立新版本并填写 `supersedes`，不要直接删除历史记录。

## 清理原则

- 删除重复内容，但保留来源关系。
- 归档失效内容，不直接抹除可追溯历史。
- 对低置信度、无来源或无法复现的内容降级。
- 对包含敏感信息的内容执行权限控制、脱敏或删除。

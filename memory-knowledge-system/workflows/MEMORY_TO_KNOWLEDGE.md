# 记忆转知识工作流

## 触发条件

当一条记忆具有跨任务复用价值、已形成稳定结论或能指导他人执行时，启动此流程。

## 步骤

1. 读取记忆原文和上下文。
2. 分离事实、判断、假设和建议。
3. 检查来源、验证结果、适用范围和潜在冲突。
4. 选择知识分类和生命周期。
5. 使用知识模板建立新文件。
6. 将原记忆 ID 写入 `source_memory`。
7. 将知识 ID回写到原记忆的 `related_knowledge`。
8. 执行完整性、可读性、准确性、可用性、时效性和可追溯性检查。
9. 将状态设为 `draft`、`reviewed` 或 `active`。
10. 更新知识索引。

## 禁止事项

- 不把未经验证的单次猜测写成 `active` 知识。
- 不删除原始记忆以替代来源追溯。
- 不把多个互相冲突的结论合并成无条件规则。
- 不丢弃适用范围、例外和验证日期。
